## 2. Flight Booking Process

### Step 4: Search Flights
Select "Practice Booking" from the hub.
![Booking Search](../C:/Users/Crissaunt/.gemini/antigravity/brain/98ab71ee-7bab-4c02-b292-edb4f9c50336/booking_search_v2_1778349388485.png)
1. Choose **One Way** or **Round Trip**.
2. Enter **Origin** (e.g., MNL) and **Destination** (e.g., DVO).
3. Select your **Departure Date**.
4. Click **SEARCH FLIGHTS**.

### Step 5: Select a Flight
Browse the available flights and select the one that fits your schedule.
![Flight Results](../C:/Users/Crissaunt/.gemini/antigravity/brain/98ab71ee-7bab-4c02-b292-edb4f9c50336/flight_results_page_with_flights_1778350564925.png)
*Check the flight number, departure time, and price before proceeding.*
